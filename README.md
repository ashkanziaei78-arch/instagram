# IG Auto Suite

اپ دسکتاپ (ویندوز/مک/لینوکس) برای اتوماسیون و مدیریت اینستاگرام: کامنت‌به‌دایرکت، پیام خوشامد به فالوور جدید، اعلام پست جدید به فالوورها، پاسخ خودکار به کلیدواژه در دایرکت، و آنالیتیکس.

ساخته‌شده با Electron + React + TypeScript + SQLite. همه‌چیز روی کامپیوتر خودتان اجرا می‌شود — هیچ سروری در میان نیست و هیچ داده‌ای جایی فرستاده نمی‌شود.

## قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| **کامنت → دایرکت** | کاربر عدد یا کلمه‌ای را کامنت می‌کند، خودکار دایرکت می‌گیرد. با پشتیبانی کامل از ارقام فارسی. |
| **پاسخ عمومی به کامنت** | همراه دایرکت، زیر کامنت هم جواب می‌گذارد |
| **خوشامد به فالوور جدید** | هر کسی فالو کند، پیام خوشامد می‌گیرد |
| **اعلام پست جدید** | با انتشار پست، به فالوورها/فالووینگ دایرکت می‌رود |
| **کلیدواژه در دایرکت** | پاسخ خودکار به پیام‌هایی که کلمه‌ی خاصی دارند |
| **ارسال گروهی** | دایرکت انبوه با فیلتر مخاطب و کنترل کامل |
| **آنالیتیکس** | ویو، ریچ، لایک، کامنت، سیو، نرخ تعامل، نمودار رشد فالوور |
| **مخاطبان** | لیست فالوور/فالووینگ، برچسب‌گذاری، وضعیت پنجره‌ی ۲۴ ساعته |
| **سیستم ایمنی** | سقف روزانه، تأخیر انسانی، ساعات سکوت، گرم‌کردن، توقف اضطراری |
| **چند حساب** | هر حساب قوانین و آمار جداگانه دارد |

## ⚠️ اول این را بخوانید: API اینستاگرام چه اجازه‌ای می‌دهد

این مهم‌ترین بخش این فایل است. API رسمی اینستاگرام سه کار را **به هیچ روشی** اجازه نمی‌دهد:

| خواسته | API رسمی | راه موجود |
|---|---|---|
| گرفتن لیست فالوورها | ❌ اندپوینتی وجود ندارد (فقط تعداد) | ورود ساده |
| فهمیدن «چه کسی الان فالو کرد» | ❌ چنین وبهوکی نیست | ورود ساده + مقایسه‌ی لیست |
| دایرکت به کسی که پیام نداده | ❌ قانون پنجره‌ی ۲۴ ساعته | ورود ساده |
| کامنت → دایرکت | ✅ کامل | **موتور رسمی** |
| آمار ویو/ریچ/سیو | ✅ کامل | **موتور رسمی** |
| پاسخ به کامنت | ✅ کامل | **موتور رسمی** |

برای این سه مورد، اپ **دو راه اتصال** دارد که می‌توانید هر دو را هم‌زمان وصل کنید:

### ۱. ورود ساده با اینستاگرام — ساده‌ترین راه، پیش‌فرض

یک کلیک. پنجره‌ی خود اینستاگرام باز می‌شود، وارد می‌شوید، تمام.

- ✅ هیچ تنظیمی لازم نیست — نه اپ متا، نه App Secret، نه Redirect URI
- ✅ رمز شما وارد این اپ نمی‌شود؛ مستقیم در صفحه‌ی اینستاگرام تایپ می‌شود
- ✅ دو مرحله‌ای و تأیید هویت را خود اینستاگرام مدیریت می‌کند
- ✅ حساب لازم نیست Business باشد
- ✅ لیست فالوور، فالوور جدید و دایرکت انبوه کار می‌کند
- ⚠️ رسمی نیست — ریسک محدود شدن حساب دارد
- ⚠️ آمار ریچ و سیو نمی‌دهد

اپ فقط کوکی نشست را از پنجره برمی‌دارد و بعد همان درخواست‌هایی را می‌زند که
مرورگر شما می‌زند.

### ۲. API رسمی — بی‌ریسک، ولی راه‌اندازی دارد

- ✅ هیچ ریسکی برای حساب ندارد
- ✅ پاسخ خصوصی به کامنت (بهترین حالت کامنت‌به‌دایرکت)
- ✅ آمار دقیق: ویو، ریچ، سیو، اشتراک‌گذاری
- ⚠️ حدود ۱۰ دقیقه راه‌اندازی: ساخت اپ در داشبورد متا ([راهنما](docs/SETUP-META-APP.md))
- ⚠️ حساب باید Business یا Creator باشد

**پیشنهاد عملی:** با ورود ساده شروع کنید. بعداً اگر آمار دقیق خواستید، همان حساب
را با API رسمی هم وصل کنید — اپ خودش برای هر کار موتور مناسب را انتخاب می‌کند.

### ۳. نام کاربری و رمز — فقط پشتیبان، معمولاً کار نمی‌کند

این مسیر از کتابخانه‌ی `instagram-private-api` استفاده می‌کند که نسخه‌ی قدیمی اپ
موبایل را اعلام می‌کند. اینستاگرام اغلب با پیام
`Your version of Instagram is out of date` ردش می‌کند. فقط به‌عنوان پشتیبان
نگه داشته شده.

جزئیات کامل محدودیت‌ها: [docs/LIMITS.md](docs/LIMITS.md)

## نصب و اجرا

```bash
npm install
```

اگر پیام `Electron failed to install correctly` گرفتید (روی شبکه‌های با دسترسی محدود شایع است):

```bash
npm run fix:electron
```

سپس:

```bash
npm run dev
```

```bash
npm run pack:win
```

فایل نصبی در پوشه‌ی `release/` ساخته می‌شود.

```bash
npm test
```

۱۶۳ بررسی روی لایه‌ی دیتابیس، موتور تطبیق، ابزارهای متنی و موتور وب.

## شروع سریع: اولین قانون کامنت‌به‌دایرکت

1. **حساب‌ها** → **+ ورود ساده با اینستاگرام** → در پنجره‌ای که باز می‌شود وارد شوید
2. **آنالیتیکس** → **همگام‌سازی پست‌ها** (تا اپ پست‌هایتان را بشناسد)
3. **اتوماسیون‌ها** → **+ قانون جدید**:
   - نام: `عدد ۱ → لینک محصول`
   - تریگر: `کامنت با کلیدواژه یا عدد`
   - حالت تطبیق: `عدد`
   - کلیدواژه: `1`
   - اکشن ۱ → دایرکت: `{سلام|درود} {{username}} جان! لینکی که خواستی: https://...`
   - اکشن ۲ → پاسخ کامنت: `دایرکت رو چک کن 📩`
4. **ذخیره** → در کادر آبی پایین همان پنجره، متن `۱` را بنویسید و **تست** بزنید

تست هیچ پیامی نمی‌فرستد — فقط نشان می‌دهد قانون تطبیق می‌دهد و پیام نهایی چه شکلی است.

## نکات مهم برای اینکه حساب محدود نشود

اینستاگرام **حجم** را نمی‌بیند، **الگو** را می‌بیند.

- ۵۰ دایرکت پخش‌شده در روز: مشکلی ندارد
- همان ۵۰ دایرکت در ۱۰ دقیقه: تقریباً همیشه محدودیت

اپ به‌صورت پیش‌فرض این‌ها را رعایت می‌کند:

- **سقف روزانه** ۵۰ دایرکت (قابل تغییر، ولی پایین‌تر بهتر از بالاتر)
- **تأخیر انسانی** ۲۵ تا ۹۰ ثانیه بین ارسال‌ها
- **ساعات سکوت** ۱ تا ۸ بامداد
- **دوره‌ی گرم‌کردن** حساب تازه با ۲۰٪ سقف شروع می‌کند
- **Spintax** — `{سلام|درود}` هر پیام را کمی متفاوت می‌کند (پیام عین‌به‌عین تکراری، الگوی اسپم است)
- **عقب‌نشینی تصاعدی** اگر اینستاگرام محدودیت اعلام کند، ۱۵ دقیقه → ۴۵ دقیقه → … تا ۶ ساعت صبر می‌کند
- **توقف اضطراری** در نوار کناری، همه‌چیز را فوری متوقف می‌کند

## معماری

```
src/
├── shared/       تایپ‌های مشترک و قرارداد IPC (تنها منبع حقیقت)
├── core/         منطق خالص Node — بدون وابستگی به Electron، قابل تست
│   ├── db/         SQLite + مهاجرت + repository
│   ├── engine/     GraphEngine (رسمی) / WebEngine (ورود ساده) / SessionEngine / EngineManager
│   ├── rules/      تطبیق کلیدواژه و اجرای اکشن‌ها
│   ├── queue/      صف پایدار + نگهبان ایمنی
│   ├── automations/ چهار اتوماسیون اصلی
│   └── pollers/    نظرسنجی کامنت، مدیا و فالوور
├── main/         فرایند اصلی Electron: پنجره، OAuth، ورود ساده، وبهوک، انبار رمزنگاری
├── preload/      پل امن contextBridge
└── renderer/     React + Tailwind + RTL فارسی
```

چند تصمیم طراحی که ارزش دانستن دارند:

- **صف پایدار در SQLite** — اگر اپ بسته شود، کارهای در انتظار از بین نمی‌روند. کارهایی که وسط اجرا مانده بودند در راه‌اندازی بعدی بازیابی می‌شوند.
- **جدا بودن «تأخیر» از «شکست»** — وقتی ساعات سکوت است، کار عقب می‌افتد ولی سهمیه‌ی تلاش‌هایش نمی‌سوزد. وگرنه یک شب سکوت، همه‌ی کارها را می‌کشت.
- **`dedupe_key` با ایندکس یکتای جزئی** — جلوگیری از ارسال تکراری در سطح دیتابیس، نه در کد. وبهوک متا واقعاً رویدادها را تکرار می‌فرستد.
- **محافظت خط‌مبنا** — اولین همگام‌سازی فالوورها فقط خط‌مبنا می‌سازد و هیچ پیامی نمی‌دهد. بدون آن، بار اول به تمام فالوورها پیام خوشامد می‌رفت.
- **اعتبارنامه‌ها جدا از دیتابیس** — توکن‌ها و نشست‌ها با `safeStorage` (DPAPI ویندوز) رمز می‌شوند و در فایل جدا می‌مانند، تا اگر دیتابیس پشتیبان‌گیری یا همگام‌سازی شد، اعتبارنامه لو نرود.
- **نرمال‌سازی فارسی** — ارقام فارسی/عربی، ك/ي عربی، نیم‌فاصله و ایموجی همه یکسان‌سازی می‌شوند. بدون آن نصف تریگرها بی‌صدا از دست می‌رفتند.
- **موتور وب به‌جای کتابخانه‌ی موبایل** — `instagram-private-api` نسخه‌ی منقضی اپ موبایل را اعلام می‌کند و اینستاگرام لاگینش را رد می‌کند. موتور وب همان درخواست‌هایی را می‌زند که مرورگر می‌زند، و چنین چکی وجود ندارد.
- **تأیید نشست هنگام اتصال** — بلافاصله بعد از ورود، یک فراخوانی واقعی زده می‌شود. بدون آن، اتصال «موفق» اعلام می‌شد و کاربر ساعت‌ها بعد سر اولین دایرکت می‌فهمید که وصل نشده.

## مسئولیت

این ابزار برای مدیریت حساب **خودتان** ساخته شده. ارسال پیام ناخواسته‌ی انبوه هم مخاطب را می‌آزارد و هم حساب شما را به خطر می‌اندازد. روش «ورود ساده» و «نام کاربری و رمز» شرایط استفاده‌ی اینستاگرام را نقض می‌کنند و استفاده از آن‌ها با ریسک و مسئولیت خودتان است.
