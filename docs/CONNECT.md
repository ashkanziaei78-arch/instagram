# راهنمای اتصال حساب — ساده و مرحله‌به‌مرحله

این فایل فقط یک کار دارد: اینکه حسابتان وصل شود. بدون اصطلاح فنی، بدون پیش‌نیاز.

---

## اول: کدام روش مال شماست؟

سه سؤال، جواب را می‌گیرید:

**۱. می‌خواهید سریع شروع کنید و کاری به آمار ریچ و سیو ندارید؟**
→ **ورود ساده** (پایین، بخش الف). یک کلیک. هیچ تنظیمی ندارد.

**۲. پنجره‌ی ورود باز شد و بلافاصله بسته شد، یا اصلاً بالا نیامد؟**
→ **کد نشست** (بخش ب). همیشه کار می‌کند چون اصلاً به شبکه‌ی خود اپ کاری ندارد.

**۳. حسابتان بیزنسی است و آمار دقیق یا کامنت‌به‌دایرکتِ بی‌ریسک می‌خواهید؟**
→ **API رسمی از مرورگر خودتان** (بخش ج). ۱۰ دقیقه راه‌اندازی، بعدش تمیزترین حالت.

> می‌توانید **همان حساب** را با دو روش هم‌زمان وصل کنید. اپ برای هر کار خودش
> موتور مناسب را انتخاب می‌کند: دایرکت انبوه از ورود ساده، آمار از API رسمی.

---

## الف) ورود ساده با اینستاگرام

1. اپ را باز کنید → **حساب‌ها**
2. دکمه‌ی **+ ورود ساده با اینستاگرام** را بزنید
3. پنجره‌ی خود اینستاگرام باز می‌شود → نام کاربری و رمز را **در همان پنجره** بزنید
4. اگر کد دو مرحله‌ای خواست، همان‌جا وارد کنید
5. پنجره خودش بسته می‌شود و حساب در لیست ظاهر می‌شود

رمز شما وارد اپ نمی‌شود — در صفحه‌ی خود اینستاگرام تایپ می‌شود و اپ فقط
کوکی نشست را از پنجره برمی‌دارد.

**اگر پنجره سریع بسته شد یا صفحه سفید ماند:** یعنی شبکه‌ی خود اپ به اینستاگرام
نمی‌رسد. سراغ بخش ب بروید — آن مسیر این مشکل را ندارد.

---

## ب) اتصال با کد نشست

این روش از مرورگری استفاده می‌کند که **از قبل** به اینستاگرام وصل است. پس اگر
مرورگر شما اینستاگرام را باز می‌کند، این حتماً کار می‌کند.

1. در مرورگر خودتان (کروم / فایرفاکس / اج) `instagram.com` را باز کنید و وارد شوید
2. کلید `F12` را بزنید (ابزار توسعه‌دهنده باز می‌شود)
3. تب **Application** را بزنید
   - در فایرفاکس اسمش **Storage** است
4. از ستون چپ: **Cookies** → `https://www.instagram.com`
5. در لیست، ردیف `sessionid` را پیدا کنید
6. روی مقدارش دوبار کلیک کنید، کل متن را کپی کنید
7. در اپ: **حساب‌ها** → **+ اتصال با کد نشست** → بچسبانید → **اتصال**

مقدار چیزی شبیه این است:

```
12345678%3AAbCdEf...%3A14%3AAYc...
```

**نگران فرمتش نباشید.** اپ این حالت‌ها را هم قبول می‌کند و خودش تمیز می‌کند:
- با پیشوند `sessionid=`
- کل رشته‌ی کوکی‌ها یکجا
- با گیومه‌ی تکی یا دوتایی
- با فاصله‌ی اضافه

> ⚠️ کد نشست مثل رمز عبور است. جایی نفرستید. اگر در اینستاگرام «خروج از همه‌ی
> دستگاه‌ها» بزنید باطل می‌شود و باید دوباره وصل شوید.

---

## ج) API رسمی از مرورگر خودتان (سه مرحله)

این همان روشی است که سرویس‌های آنلاین استفاده می‌کنند، با یک تفاوت: آن‌ها سرور
دارند و کد اجازه مستقیم به سرورشان می‌رسد؛ اپ دسکتاپ سرور ندارد، پس شما کد را
از نوار مرورگر برمی‌دارید و می‌چسبانید. در عوض هیچ داده‌ای از کامپیوترتان
بیرون نمی‌رود.

**پیش‌نیاز:** یک بار باید اپ متا بسازید → [راهنمای کامل](SETUP-META-APP.md)
(اگر نسخه‌ی اپ را با اعتبارنامه‌ی جاسازی‌شده بیلد کرده‌اید، این پیش‌نیاز حذف
می‌شود و کاربر هیچ تنظیمی نمی‌بیند.)

بعد از آن، در اپ: **حساب‌ها** → **+ API رسمی**. جادوگر سه مرحله‌ای باز می‌شود:

### مرحله ۱ — در مرورگر خودتان وارد اینستاگرام شوید
فیلترشکن مرورگر روشن باشد. اگر از قبل واردید، همین کافی است. **بعدی** را بزنید.

### مرحله ۲ — لینک اجازه را در همان مرورگر باز کنید
دکمه‌ی **باز کن** لینک را در مرورگر شما باز می‌کند. اینستاگرام می‌پرسد آیا به
این اپ اجازه می‌دهید → **Allow** را بزنید.

بعد از Allow، مرورگر ممکن است **صفحه‌ی خطا یا صفحه‌ی سفید** نشان دهد.
**این طبیعی است و یعنی کار درست پیش رفته.** چیزی که مهم است آدرس نوار بالای
مرورگر است، نه محتوای صفحه.

### مرحله ۳ — آدرس نوار مرورگر را بچسبانید
کل آدرس را کپی کنید (حتی اگر صفحه خطا می‌دهد) و در کادر بچسبانید → **اتصال**.
آدرس داخلش `code=` دارد. اگر فقط خود کد را هم بچسبانید کار می‌کند.

> **کد فقط یک بار مصرف است.** اگر خطا گرفتید، به مرحله‌ی ۲ برگردید و لینک را
> دوباره باز کنید تا کد تازه بگیرید. چسباندن دوباره‌ی همان آدرس جواب نمی‌دهد.

## وبهوک — به زبان خیلی ساده

### وبهوک چیست و چرا باید برایم مهم باشد؟

دو راه وجود دارد که اپ بفهمد کسی کامنت گذاشته:

| | چطور کار می‌کند | سرعت واکنش | راه‌اندازی |
|---|---|---|---|
| **نظرسنجی دوره‌ای** (پیش‌فرض) | اپ هر ۳ دقیقه می‌پرسد «کامنت جدیدی هست؟» | تا ۳ دقیقه تأخیر | ندارد |
| **وبهوک** | اینستاگرام همان لحظه به اپ خبر می‌دهد | چند ثانیه | دارد |

**اگر وبهوک را تنظیم نکنید، اپ باز هم کامل کار می‌کند** — فقط جواب دایرکت به‌جای
۵ ثانیه، تا ۳ دقیقه طول می‌کشد. اگر این برایتان قابل قبول است، این بخش را رد کنید.

### چرا راه‌اندازی دارد؟

چون اینستاگرام باید بتواند به کامپیوتر شما درخواست بزند. کامپیوتر خانگی آدرس
عمومی ندارد، پس باید یک «تونل» بسازیم که از اینترنت به کامپیوتر شما راه بدهد.

### مرحله‌به‌مرحله

**۱. برنامه‌ی تونل را بگیرید**
از [صفحه‌ی دانلود cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)
نسخه‌ی ویندوز را دانلود کنید. حساب Cloudflare لازم **نیست**. رایگان است.

**۲. تونل را روشن کنید**
یک پنجره‌ی Command Prompt باز کنید و بزنید:

```bash
cloudflared tunnel --url http://localhost:8787
```

بعد از چند ثانیه آدرسی مثل این می‌دهد:

```
https://random-words-1234.trycloudflare.com
```

**این آدرس را کپی کنید و این پنجره را نبندید.** تا وقتی باز است تونل برقرار است.

**۳. در اپ تنظیم کنید**
**تنظیمات** → کادر **Webhook Verify Token** → یک رشته‌ی دلخواه بنویسید
(مثلاً `mytoken-9821`؛ فقط باید یادتان بماند) → **ذخیره** → کلید **وبهوک** را روشن کنید.

**۴. در داشبورد متا ثبت کنید**
[developers.facebook.com/apps](https://developers.facebook.com/apps) → اپ خودتان →
**Instagram** → **Webhooks**:

- **Callback URL**: آدرس تونل + `/webhook`
  یعنی: `https://random-words-1234.trycloudflare.com/webhook`
- **Verify Token**: دقیقاً همان رشته‌ای که در اپ نوشتید
- **Verify and Save** را بزنید

اگر پیام سبز گرفتید، تمام است.

**۵. انتخاب کنید چه چیزی خبر بدهد**
در همان صفحه، لیست فیلدها را ببینید و این دو را **Subscribe** کنید:

| فیلد | برای چه کاری |
|---|---|
| `comments` | کامنت جدید → دایرکت خودکار |
| `messages` | دایرکت جدید → پاسخ به کلیدواژه |

### دو نکته‌ی مهم درباره‌ی تونل رایگان

- **آدرس هر بار عوض می‌شود.** اگر پنجره‌ی cloudflared را ببندید و دوباره باز
  کنید، آدرس جدید می‌گیرید و باید در داشبورد متا به‌روزش کنید.
- **اگر این آزاردهنده است:** یا از نظرسنجی دوره‌ای استفاده کنید (وبهوک را خاموش
  بگذارید)، یا اگر دامنه دارید آن را به تونل نامی Cloudflare وصل کنید تا آدرس
  ثابت بماند.

## اگر خطا گرفتید

| چه می‌بینید | یعنی چه | چه کار کنم |
|---|---|---|
| پنجره‌ی ورود سریع بسته می‌شود | شبکه‌ی اپ به اینستاگرام نمی‌رسد | بخش ب (کد نشست) |
| `Invalid redirect_uri` | آدرس در اپ و داشبورد متا مو‌به‌مو یکی نیست | اسلش انتهایی را چک کنید |
| `تبدیل کد به توکن ناموفق بود` | App Secret اشتباه است یا کد را دوبار استفاده کرده‌اید | به مرحله‌ی ۲ برگردید و کد تازه بگیرید |
| `کد نشست معتبر نیست` | مقدار `csrftoken` یا `mid` را کپی کرده‌اید | دنبال ردیفی بگردید که دقیقاً `sessionid` است |
| فیسبوک شماره‌ی تلفن می‌خواهد | با IP ایران برای ساخت اپ متا پیش می‌آید | بخش الف یا ب — این دو اصلاً اپ متا نمی‌خواهند |
| تأیید وبهوک ناموفق | توکن یکی نیست یا تونل خاموش است | هر دو را چک کنید |
| آمار ویو و ریچ صفر است | حساب با موتور Session وصل است | همان حساب را با API رسمی هم وصل کنید |
| توکن منقضی شد | اپ ۶۰ روز باز نشده | دوباره از بخش ج وصل شوید |
