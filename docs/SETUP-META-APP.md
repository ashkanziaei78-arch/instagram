# راهنمای ساخت اپ متا و اتصال حساب

این کار **یک بار** انجام می‌شود و بعد از آن اتصال حساب‌ها با یک کلیک است.

---

## پیش‌نیاز: حساب اینستاگرام باید Business یا Creator باشد

اگر حساب شما Personal است، API رسمی اصلاً کار نمی‌کند.

اپ اینستاگرام → منو → Settings → Account type and tools → Switch to professional account

این تغییر رایگان است و ظاهر پروفایل را برای مخاطب عوض نمی‌کند.

---

## مرحله ۱ — ساخت اپ در داشبورد متا

1. به [developers.facebook.com/apps](https://developers.facebook.com/apps) بروید و وارد شوید.
2. **Create App** را بزنید.
3. در قسمت use case، گزینه‌ی **Other** و بعد نوع **Business** را انتخاب کنید.
4. یک نام برای اپ بگذارید (هر چیزی — مخاطب شما این را نمی‌بیند).

## مرحله ۲ — افزودن محصول Instagram

1. در داشبورد اپ، از فهرست محصولات **Instagram** را پیدا و **Set up** را بزنید.
2. گزینه‌ی **API setup with Instagram login** را انتخاب کنید.

   > چرا این گزینه و نه «Facebook login»؟ چون این مسیر به صفحه‌ی فیسبوک نیاز ندارد و راه‌اندازی‌اش یک مرحله‌ای است.

## مرحله ۳ — برداشتن App ID و App Secret

در همان صفحه، بخش **3. Set up Instagram business login** → **Business login settings**:

- **Instagram app ID** را کپی کنید → در تنظیمات اپ، فیلد `App ID`
- **Instagram app secret** را کپی کنید → فیلد `App Secret`

## مرحله ۴ — تعیین Redirect URI

در همان بخش Business login settings:

1. روی **Set up** کلیک کنید.
2. در **Redirect URI**، یک آدرس HTTPS بگذارید. **هر آدرس HTTPS معتبری کار می‌کند** — لازم نیست سروری آنجا باشد:

   ```
   https://example.com/auth/callback
   ```

   > چرا مهم نیست چه آدرسی باشد؟ چون اپ دسکتاپ ما ناوبری به آن آدرس را داخل پنجره‌ی خودش رصد می‌کند و کد را از آدرس برمی‌دارد. صفحه هرگز واقعاً بارگذاری نمی‌شود.

3. **دقیقاً همان آدرس** را در تنظیمات اپ، فیلد `Redirect URI` بنویسید. یک اسلش اضافه هم باعث خطا می‌شود.

## مرحله ۵ — مجوزها

اپ این مجوزها را درخواست می‌کند:

| مجوز | برای چه کاری |
|---|---|
| `instagram_business_basic` | خواندن پروفایل و پست‌ها |
| `instagram_business_manage_messages` | ارسال دایرکت و پاسخ خصوصی به کامنت |
| `instagram_business_manage_comments` | خواندن کامنت‌ها و پاسخ عمومی |
| `instagram_business_manage_insights` | آمار ویو، ریچ و سیو |
| `instagram_business_content_publish` | (برای قابلیت‌های آینده) |

در حالت **Development** اپ، این مجوزها برای حساب‌هایی که به‌عنوان تستر اضافه کرده‌اید بدون بازبینی متا کار می‌کنند. برای استفاده روی حساب‌های دیگر باید App Review بگیرید — که برای استفاده‌ی شخصی لازم نیست.

## مرحله ۶ — اتصال حساب در اپ

1. اپ را باز کنید → **تنظیمات** → مقادیر بالا را وارد و ذخیره کنید.
2. **حساب‌ها** → **+ اتصال با API رسمی**.
3. پنجره‌ی ورود اینستاگرام باز می‌شود → وارد شوید و دسترسی را تأیید کنید.
4. پنجره خودکار بسته می‌شود و حساب در لیست ظاهر می‌شود.

## مرحله ۷ (اختیاری) — وبهوک برای واکنش لحظه‌ای

**اگر این مرحله را انجام ندهید، اپ باز هم کامل کار می‌کند** — فقط با چند دقیقه تأخیر (نظرسنجی دوره‌ای هر ۳ دقیقه کامنت‌ها را چک می‌کند). اگر واکنش در همان ثانیه می‌خواهید، ادامه دهید.

متا باید بتواند به کامپیوتر شما درخواست بزند، پس به یک آدرس عمومی HTTPS نیاز است.

### ۷.۱ — نصب cloudflared

از [صفحه‌ی دانلود cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) نسخه‌ی ویندوز را بگیرید. حساب Cloudflare لازم نیست.

### ۷.۲ — روشن کردن تونل

```bash
cloudflared tunnel --url http://localhost:8787
```

آدرسی مثل `https://random-words-1234.trycloudflare.com` می‌دهد. **این پنجره را باز نگه دارید.**

### ۷.۳ — تنظیم در اپ

تنظیمات → یک **Webhook Verify Token** بنویسید (هر رشته‌ای، مثلاً `my-token-9821`) → ذخیره → کلید **وبهوک** را روشن کنید.

### ۷.۴ — ثبت در داشبورد متا

داشبورد اپ → Instagram → **Webhooks**:

- **Callback URL**: آدرس تونل + `/webhook`
  مثال: `https://random-words-1234.trycloudflare.com/webhook`
- **Verify Token**: همان رشته‌ای که در اپ نوشتید
- **Verify and Save** را بزنید

سپس در لیست فیلدها، این دو را Subscribe کنید:
- `comments` — برای کامنت به دایرکت
- `messages` — برای پاسخ به کلیدواژه در دایرکت

> **نکته:** آدرس تونل رایگان cloudflared هر بار که آن را ببندید و باز کنید عوض می‌شود و باید در داشبورد متا به‌روز شود. اگر این آزاردهنده است، از نظرسنجی دوره‌ای استفاده کنید یا یک دامنه‌ی خودتان را به تونل نامی Cloudflare وصل کنید.

## عیب‌یابی

| خطا | علت و راه‌حل |
|---|---|
| `Invalid redirect_uri` | آدرس در اپ و داشبورد متا مو‌به‌مو یکی نیست. اسلش انتهایی را چک کنید. |
| `تبدیل کد به توکن ناموفق بود` | App Secret اشتباه است، یا Redirect URI نمی‌خواند. |
| توکن منقضی شد | توکن ۶۰ روزه است و اپ خودکار تازه‌اش می‌کند. اگر اپ ۶۰ روز باز نشده باشد، باید دستی دوباره وصل شوید. |
| تأیید وبهوک ناموفق | Verify Token در اپ و داشبورد یکی نیست، یا تونل خاموش است. |
| آمار ویو و ریچ صفر است | حساب با موتور Session وصل است نه API رسمی. آمار دقیق فقط از API رسمی می‌آید. |
| `مجوز لازم داده نشده` | در پنجره‌ی ورود، همه‌ی دسترسی‌ها را تأیید نکرده‌اید. حساب را حذف و دوباره وصل کنید. |
